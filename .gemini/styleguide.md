# 리뷰 가이드 (Gemini Code Assist)

리뷰는 한국어로 짧게 쓴다. 스타일 지적보다 동작이 틀릴 수 있는 곳을 먼저 본다.

이 레포의 규칙은 루트의 `AGENTS.md`에 있다. 특히 아래를 어기면 꼭 지적한다.
- 재무 수치·스코어카드 가중합을 LLM 출력으로 계산하는 코드
- 실행 상한을 `invest_agent/config.py` 밖(프롬프트 등)에서 처리하는 코드
- 작성 모델이 스코어카드·재무 표를 직접 만들게 하는 변경
- API 키나 `.env` 내용이 들어간 커밋
- 테스트(`tests/`) 없이 Supervisor 분기 로직을 바꾸는 변경
